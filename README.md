# Dance Course Frontend

Multilingual website for online and offline dance courses.

## Local development

Requires Node.js `24.18.x` and npm. The expected Node version is also stored in `.nvmrc`.

```bash
nvm use
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Commands

```bash
npm run dev          # Start the development server
npm run build        # Create a production build
npm run start        # Start the production server
npm test             # Run unit tests
npm run test:e2e     # Run Playwright tests
npm run typecheck    # Check TypeScript
npm run check        # Check formatting and linting
npm run verify       # Run the standard validation suite
```
